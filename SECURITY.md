# 安全报告 / Security policy

请勿在公开 Issue 披露密钥、业务数据或可直接利用的漏洞细节。请通过 [fayne.guo@gmail.com](mailto:fayne.guo@gmail.com) 私下提供受影响版本、复现步骤、影响和建议。确认修复前请协调披露时间。

Report vulnerabilities privately to [fayne.guo@gmail.com](mailto:fayne.guo@gmail.com), including affected versions, reproduction steps and impact. Do not post credentials, business data or exploit details in public issues. Coordinate disclosure before publishing details.
